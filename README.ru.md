# StockFlow WMS

Система управления складом, предназначенная для реальных процессов
учёта запасов и выполнения складских операций.

[English](README.md) | [Русский](README.ru.md)

## О системе

StockFlow WMS — модульная система управления складом для работы
с запасами, складскими операциями, заказами и связанными процессами.

Система построена на основе независимо разворачиваемых сервисов
и асинхронной обработки, с акцентом на надёжность, наблюдаемость
и предсказуемую работу под нагрузкой.

Проект находится в активной разработке.

## Основные возможности

- Управление складами и запасами
- Учёт товаров и остатков
- Обработка заказов
- Резервирование запасов
- Складские операции и процессы комплектации
- Асинхронная обработка фоновых задач
- Событийное взаимодействие сервисов
- Аутентификация и авторизация
- Мониторинг и observability

Дополнительные возможности добавляются по мере развития системы.

## Архитектура

Система построена на микросервисной архитектуре с чёткими границами
ответственности отдельных сервисов.

Для взаимодействия используются синхронные API и асинхронный обмен
сообщениями в тех случаях, где это необходимо.

Каждый сервис отвечает за собственную бизнес-логику и данные,
что позволяет минимизировать связанность между компонентами системы.

Подробная архитектурная документация находится в [`docs/`](docs/)
и обновляется вместе с архитектурными изменениями.
